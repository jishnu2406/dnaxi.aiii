Architecture, readable by machines.

Drawings hold far more than lines. DNAX extracts the structure and keeps it queryable.

Geometry

Walls, rooms, doors, windows, dimensions, structural elements.

Contents

Furniture, fixtures, zones and circulation paths.

Relationships

Adjacency, access, daylight exposure and area per space.

Documents

Briefs, specifications and standards linked to the spaces they govern.

System architecture

Computer vision understands the geometry. Claude reasons about the project. Deterministic checks validate the result.

Ingest

PDF, DWG, IFC, images, briefs, specifications.

Detect

CV model: wall mask, openings, room segmentation, object classes.

Spatial graph

Shapely and NetworkX build rooms, edges and metrics.

Retrieve

Project documents and standards via pgvector.

Reason

Claude API receives graph, brief and context.

Validate

Schema and rule checks before anything reaches the user.

Reasoning layer, not a chat box.

DNAX is designed around the Claude API as its reasoning layer across spatial data, specifications and requirements, returning structured output that is validated before use.

  • Does the current design satisfy the client's brief?
  • Compare Revision 07 with Revision 06. Which rooms changed?
  • Find conflicts between the drawing and specification.
  • Generate a room-by-room design brief.
